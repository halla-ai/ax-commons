# Facilitator guide / 진행자 안내

Status: ready for review; partner approval, participant notice and pilot delivery are pending human action.

## Preparation / 준비

- Obtain the partner's approval, select the dates and appoint an operator contact and domain reviewers. Complete and distribute the [participation notice](consent-notice.md) before any measurement; offer a private question channel. Do not infer consent from silence or attendance.
- 협력기관 승인, 일정, 담당 연락처, 분야 검토자를 확정합니다. 측정 전에 [참여 안내](consent-notice.md)를 완성·전달하고 개별 질문 경로를 제공합니다. 침묵이나 참석만으로 동의를 추정하지 않습니다.
- Use ChatGPT and Claude, the approved pilot scope. Check the [support matrix](../support-matrix.md) and actual participant app before installation. Claude Desktop is the documented local-server route; ChatGPT exercises use the same instructions without local MCP. Do not claim a remote connector exists for this pilot.
- 승인된 파일럿 범위인 ChatGPT와 Claude를 사용합니다. [지원 표](../support-matrix.md)와 참가자의 실제 앱을 확인합니다. Claude Desktop은 문서화된 로컬 서버 경로이며, ChatGPT에서는 로컬 MCP 없이 동일 지침을 사용합니다.
- Confirm the P1 release and installation guide exist before offering installation. Confirm P2 before offering contribution submission, and P3 before metrics sync. Until then, use standalone skills and local drafts. State which steps are unavailable.
- 설치를 안내하기 전에 P1 배포와 설치 안내를 확인합니다. 기여물 제출은 P2, 지표 동기화는 P3 제공 여부를 먼저 확인합니다. 미제공 단계는 독립 스킬과 로컬 초안을 사용하고 제한을 알립니다.
- Preview all [fictional exercises](fictional-exercises.md). Do not import workplace files or ask for customer details to make an example realistic.
- [가상 실습](fictional-exercises.md)을 사전 확인합니다. 현장 파일이나 고객 정보를 반입하지 않습니다.

## Session one / 1차 교육

- Explain the notice and distinguish local logging, optional sharing and support. Record only an aggregate notice-delivery count after explanation. Any required human approval remains a separate, operator-managed process.
- 안내 내용을 설명하고 로컬 기록·선택적 공유·지원을 구분합니다. 설명 후 안내 전달 건수만 집계합니다. 필요한 사람의 승인은 운영자가 별도로 관리합니다.
- Offer the install route only to supported participants who attempt it. Measure from opening the guide/package to the first successful local `log_task` entry; use an observer's timer and the visible tool confirmation, not an assumption from package download.
- 지원되는 앱에서 설치를 시도하는 참가자에게만 설치 경로를 제공합니다. 안내·패키지를 연 시점부터 첫 `log_task` 성공 확인까지 관찰자의 타이머로 측정합니다. 다운로드를 성공 기록으로 취급하지 않습니다.
- Participants select one fictional exercise and declare a work category if the local tool is available. Have them review a draft against the supplied facts before revising it.
- 참가자는 가상 실습 하나를 선택합니다. 로컬 도구가 있으면 작업 종류를 선언하고, 초안을 제공 사실과 대조한 뒤 수정합니다.
- Log category and actual review/reuse flags using the installed tool's schema. The standalone route still completes the exercise; any manual counting is kept separate from MCP counts.
- 설치된 도구의 스키마에 맞춰 분류와 실제 검토·재사용 여부를 기록합니다. 독립 실행도 실습 완료로 인정하며 수기 집계와 MCP 집계를 구분합니다.

## Session two / 2차 교육

- Retrieve the selected skill and repeat a fictional task with changed facts. A reusable skill is a task procedure, not a copy of a conversation.
- 선택한 스킬로 사실을 변경한 가상 작업을 반복합니다. 재사용 스킬은 작업 절차이며 대화문 사본이 아닙니다.
- Ask participants to identify one failure or unsupported claim and correct it. Failure reports count as learning; do not rank participants by contribution volume.
- 실패나 근거 없는 주장 하나를 찾아 수정합니다. 실패 보고도 학습으로 인정하며 기여량으로 참가자 순위를 매기지 않습니다.
- Save the chosen skill locally in the format the app supports. If skill installation is unavailable, retain the instructions as a local document and report that limitation.
- 앱이 지원하는 형식으로 스킬을 로컬에 저장합니다. 스킬 설치가 불가능하면 지침을 로컬 문서로 남기고 제한을 보고합니다.
- With P2 unavailable, stop at a local contribution draft. With P2 available, use its preview, scope, expiry and approval flow; a facilitator may not approve on a participant's behalf.
- P2가 없으면 로컬 기여 초안에서 끝냅니다. 제공되면 미리보기·범위·기간·승인 흐름을 사용하며 진행자가 참가자 대신 승인하지 않습니다.

## Closeout / 종료

- Use the [measurement plan](measurement-plan.md) and [report template](report-template.md). Verify deletion guidance with the actual released tools, and tell participants that exports need separate deletion.
- [측정 계획](measurement-plan.md)과 [보고 양식](report-template.md)을 사용합니다. 실제 배포 도구로 삭제 안내를 확인하고, 내보낸 파일은 별도 삭제가 필요함을 알립니다.
- Do not publish raw small-cohort counts or a participant-level spreadsheet. Apply suppression before any report leaves the device. Leave unknowns as unknown, and label timed technical tests separately from non-developer observations.
- 원시 소규모 집계나 개인별 표를 게시하지 않습니다. 기기 밖으로 보고하기 전에 소규모 셀을 비공개 처리합니다. 미확인은 미확인으로 남기고 기술 시험과 비개발자 관찰 결과를 구분합니다.
